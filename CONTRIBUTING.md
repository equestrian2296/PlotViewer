# Contributing to Plot Viewer

Thank you for considering contributing to Plot Viewer.

## Code of Conduct

- All participants are expected to adhere to a professional code of conduct.
- Please communicate respectfully and constructively.
- Report any issues to the project maintainer.


## How to Contribute

### 1. Fork the Repository

- Use GitHub to fork the repository and clone it to your local machine:

```bash
git clone https://github.com/your-username/plot-viewer.git
cd plot-viewer
```

### 2. Create a Feature Branch

- Create a new branch for your feature:

```bash
git checkout -b feature/your-feature-name
```

### 3. Make and Test Your Changes

- Ensure your changes follow these standards:
  - Functional components with hooks
  - Responsive and accessible UI
  - No hardcoded values or secrets
  - Tested for both CSV and Excel files


### 4. Commit Your Changes

- Use clear, descriptive commit messages:

```bash
git add .
git commit -m "Add: support for pie chart rendering"
```

### 5. Push and Create a Pull Request

- Push your changes to the feature branch:

```bash
git push origin feature/your-feature-name
```

- Then open a pull request to the main repository. Include a summary and link to any related issues.


## Contribution Areas

- UI/UX enhancements
- New chart types
- Backend integration (file storage, user sessions)
- Performance improvements
- Accessibility and responsiveness


## Reporting Bugs

- Use the Issues tab to report bugs.
- Please include steps to reproduce, expected behavior, and screenshots if applicable.
